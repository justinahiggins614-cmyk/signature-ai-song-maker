# Studio redesign reference images — 2026-10-02

Manon's order: "Lookup images of high-tech expensive studios and design it like that."
These three references drove `assets/studio-theme.css` (dark console, glowing
meters, premium hardware; Signature gold identity kept).

1. `ref-console.jpg` — high-end control room: dark mixing console, warm amber/gold
   room lighting, backlit faders and glowing buttons.
   Source: https://www.smstudioinc.com (via image search)
   Direct: https://www.smstudioinc.com/_next/image?url=%2Fapi%2Fmedia%2Ffile%2Fprofessional-grade-home-recording-studio.png&w=750&q=75
2. `ref-control-room.jpg` — control room with rack gear and monitors, low warm light.
   Source: https://www.artofit.org/image-gallery/806566614536983050/how-to-make-a-home-recording-studio-the-ultimate-guide/
3. `ref-rack.jpg` — studio equipment wall / outboard rack.
   Source: https://tunestreets.com/instruments-gear/

Design takeaways applied: near-black console surfaces, warm gold top-edge light
strips on rack units, backlit gold/teal/violet buttons with glow, recessed dark
input slots with gold focus rings, gold fader knobs, glowing LED meter bars.
